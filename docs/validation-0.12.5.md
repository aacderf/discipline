# 自律 0.12.5 · 视觉层级与卡片排版

本轮增加 MetaPill、MetricValueText，并调整今天、计划管理、专注、统计、应用使用和地图 HUD 的展示结构。版本号 0.12.5，versionCode 50。

- 今天主卡的状态与数量分列在进度条上方；截止、全天/有效时段改为状态胶囊，置顶保留在标题行。接下来标题与已完成数量合并，原进度轨道及成功后交接反馈保留。
- 管理计划保留已存在的顶栏数量、加号和单行地点工具栏；目标、地点、截止等改为紧凑胶囊，没有当前任务时显示“暂无待执行”。
- 专注页任务选择改为胶囊控制，配置栏移到沙漏卡片内部；空闲时显示预计结束时间，与进度在固定行内。原配置输入、任务选择、开始、暂停、继续与结束调用保留。
- 统计概览改为左主右辅结构，范围/更新状态在右上角原位换字，到场汇总用胶囊，统计规则默认收起。计时单位与比例统一使用数值组件。应用使用页保留已有分段切换和勾选跳转条，主要时长改用同一组件。
- 地图保留顶部渐变保护与居中手绘提示；横纵尺寸移至面板标题右侧，顶点/删除/撤销在辅助行，底部只保留重画与确认。独立清空按钮移除，原清空函数与一次撤销、放弃修改拦截和保存实现不变。

验证：

- Debug、AndroidTest、Release 编译通过；最终 lint 0 errors、59 warnings。没有新增依赖。
