# 自律 0.12.0 验收说明

2026-10-13 · versionCode 45 · 最低 API 26／目标 API 36 · 原签名正式 APK。

## 本轮交付

- 本机近七天应用使用报告：总时长、日均、每日趋势及应用分布，系统缺失日期显示未知。
- 在“统计 → 应用使用与下周计划”或“专注 → 应用限额”进入。用户填写自己的 DeepSeek API Key，所选使用摘要经确认后发送至官方 V4.1 Flash 接口 `deepseek-flash`；建议可编辑，确认后才启用。
- 下周限额从周一开始，为期一周；重叠时取更严格的正值，到期恢复长期规则。限额状态及悬浮面板复用同一有效规则。Key 加密存本机、不进备份；草稿与周计划进入现有版本 4 备份。
- 默认至少 24 小时的长地点任务只按已记录停留结算，缺口不算完成；较短任务仍按原待核验规则。晚发现截止时，未完成限制从实际结算开始；尚未到达的指定钟点保留，旧已结算惩罚不重排。试运行、每日上限、受保护应用仍有效。
- 旧版本尚未结算的长地点待核验任务也执行该政策；已完成或已有惩罚的结果不重排。最终增加旧待核验任务回归，并单独重跑这一受影响用例。
- 限额读取共享系统汇总缓存；切换应用重新读取。分析按需在 IO 线程整理，不增加持续分析或上传工作。关机／重启边界不延续旧事件，历史日期使用系统日汇总，避免缺失结束事件虚增时长。

## 已验证

- 54 项本地单元测试通过，包括日期裁切、重叠活动、重启断点、限额合并与延迟处罚时间。
- API 36 专用模拟器 `.qa` 包共 12 项不同设备专项通过：9 项分析／结算逻辑、2 项 UI、1 项备用模式回归。最终历史修复后重跑分析及 UI 11 项通过；备用模式专项此前已通过。
- 使用模拟 DeepSeek 响应验证请求仅包含审核的摘要、未选择应用与非法整数被拒绝、截断结果不启用规则；Key 密文与备份排除、周一生效／到期恢复、停用、备份校验、长任务幂等结算及旧确认状态保护通过。
- 缓存验证：同一窗口内两个应用共用一次汇总，应用切换仍发起新读取。备用查询熄屏暂停、无障碍恢复后接管通过。没有据此声称实际耗电或拦截延迟降低多少。
- 320dp 小屏查看报告、授权提示、Key 配置及编辑确认；检查浅色、深色和 1.3 倍字号。历史原生使用报告与系统日汇总一致；模拟器长期留存记录不代表真实手机日常使用。
- Debug、AndroidTest、Release 构建通过；lintDebug 0 错误、58 项警告。新增三项为 SharedPreferences 写法提示，其中加密保存使用 IO 线程同步提交以反馈写入失败，未屏蔽警告。
- 正式包从 0.11.9 原签名覆盖至 0.12.0，安装与冷启动成功；没有清除正式数据，也未逐项核对全部历史数据。

## 未完成实测的边界

- 未提供真实 DeepSeek Key，未执行计费 API 分析；模型可用性由 App 内“验证连接”检查。系统使用记录本身可能延后、不完整或受多窗口影响。
- 未量化真机帧耗时、30 分钟后台 CPU、实际续航或厂商拦截延迟；未重跑全机型矩阵、长期后台、实地 GPS 或完整 TalkBack 人工体验。
- 无障碍及尽力备用模式仍依赖系统授权；普通应用无法阻止强停、卸载或权限撤销。
