# 0.12.4：按录屏修复切页衔接

版本 0.12.4 / versionCode 49，2026-10-14。

## 录屏发现与修改

分析用户提供的 7.73 秒、30fps 录屏，重点查看进入／退出设置、计划管理及四个底部页面的切换帧。约 5.33 秒课表正文已出现而标题仍为今天；后续专注、统计的切换存在相同错拍和旧页淡影。静态截图与上一轮字体耗时下降不能证明这段转场已经正确。

原实现分别动画标题和正文：正文以 92% 初始透明度进入，标题延后 50ms 出现；普通全屏子页仅移动 12dp，却立即用不透明底板覆盖原页，视觉上接近突然替换后轻微漂移。

- 主页面标题与正文合并到一个 AnimatedContent 图层；旧页快速退出，新页协调出现，不再单独动画顶部标题。
- 今天的加号同属今天页图层，避免返回今天时先出现在尚未退场的统计页上。保持原有 56dp 入口、点击动作、箭头避让和动画途中可点击。
- 普通全屏子页使用整页宽度滑入与原路退出，底页仅做四分之一宽度的随动，保持实色主题背景。设置内部页面采用相同位置关系。
- 任务详情原有共享动画分支、预测返回取消、页面状态保存、深色底板及 motionEnabled=false 分支保留。

## 验证与限度

- 同一专用 API 36 模拟器检查 11 项合成计划场景；没有读取或清空正式版任务数据。
- 旧版 0.12.3 在“整页进入应有可见空间移动”的检查中失败；新版本通过。颜色一致性检查在新旧两版的所选检查点均通过，不能单凭该检查推导旧版整段转场没有问题；录屏与源码时序是定位依据。
- 5 个不同的定向检查通过：切页标题／正文表现、快速连续导航和关闭动画终态、子页空间进入及返回原任务、动画途中创建、内部返回取消与滚动恢复、深色返回不露浅色底板。部分场景合并于同一测试方法。
- 全宽转场会暂时保留两个返回节点，旧节点已由原有退出保护隐藏；测试改为选择当前可访问页的返回控件。深色检测改为检测成片的中性浅色区域，避免将正常深色卡片（绿色通道 61）或薄荷按钮误判为白闪。没有删除生产代码的语义保护。
- 补录设置、计划管理及底部页面往返，在关键帧中检查整体衔接。发现加号提前出现后，将其纳入今天页图层，并重新验证动画途中创建行为。
- Debug、AndroidTest、Release 构建通过；lint 为 0 errors、59 warnings。生产修改范围为 ComposeMainActivity.kt、ComposeSubpageMotion.kt；原有 5 处 testTag 与 8 段显式 semantics 对比保留，任务结算、Engine、Store、BlockService、围栏、限额与统计计算源码未变。
- 原签名构建并覆盖安装到专用模拟器的正式包；不更改数据库、备份格式或权限种类，保留未压缩字体资源。

用户录屏可以确认视觉错拍，无法直接量化该手机的 CPU／GPU 耗时。补录和自动检查来自模拟器，没有连接用户真机，不宣称已经证明所有设备的帧率提升。
