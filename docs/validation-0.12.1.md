# 自律 0.12.1 验收说明

2026-10-13 · versionCode 46 · 最低 API 26、目标 API 36。

## 功能与衔接

- “应用使用与下周计划 → 手动安排下周”可直接选择应用和填写限额，不要求使用情况授权或 AI Key。
- 当前周及下周已存计划可调整应用和额度、停用、恢复、删除。调整保留原启用状态，已用时长不清零；与长期限额取更严格的有效值。删除仅取消该周规则，长期配置和系统使用记录保留。
- 旧编辑窗口不会覆盖已变化的计划，也不会重新创建已删除的记录。手动新增拒绝静默替换同周已有计划；过期计划不能恢复。
- 接受 AI 建议时，周计划保存与对应草稿清除在同一事务内完成，其他更新的草稿保留。过期建议仅可查看、清除。使用报告跨日重新加载，刷新后只分析当前仍有效的所选应用。
- 多应用额度使用独立编辑页；键盘缩小内容视口，字段保持可见，旋转保留输入。字段和移除动作提供应用名称语义。

## 实际验证

- 54 项现有单元测试通过，Debug、AndroidTest、Release 构建成功；最终 lintDebug 为 0 错误、58 项警告，未扩大或屏蔽旧警告。
- API 36 专用模拟器 `.qa` 包通过 14 项不同专项：11 项使用分析／周计划／结算逻辑，3 项 UI。键盘修复后仅重跑受影响 UI 三项，均通过。
- 新增逻辑验证覆盖：手动新建及同周冲突、当前周调整、停用后保持状态、恢复、删除后回到长期规则、旧窗口拒绝覆盖／复建、匹配草稿清除、新草稿保护、过期恢复拒绝及备份校验。
- 在 320dp、1.3 倍字号下从应用选择到保存、修改、停用、恢复、删除完整操作通过。实际显示键盘时，焦点字段底部未越过键盘顶边；Activity 重建后保留 45／180 分钟草稿，字段读屏名称存在。浅色编辑页面截图已检查。
- 原签名正式包从 0.12.0 覆盖升级至 0.12.1，安装成功并冷启动；未清除正式数据，未逐项核对全部历史记录。
