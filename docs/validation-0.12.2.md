# 自律 0.12.2：前三阶段 UI／UX 修复

版本：0.12.2 / versionCode 47。2026-10-14。

## 修改

第一阶段：独立标题字体、内置 Noto Sans SC 正文和数字、补全 Material 15 个字体槽位；提高禁用文字对比与深色表面明度；不透明子页滑动、错峰换字、实色确认弹窗、32% 原生遮罩、统一开关与复选框。

第二阶段：统计周期固定、刷新提示原位更新、时长改为数字与单位基线对齐、零记录引导；七天日程条按宽度均分，大字号滚动定位；计划管理删除首屏大卡片、合并地点工具、统一加号入口；今天置顶移到头部、折叠行展开并避让加号。

第三阶段：专注标题直达任务选择、仪器上下内边距减少 16dp、小屏横向排布、说明原位切换、操作区高度固定；应用使用与下周计划增加固定切换和已选应用入口；地图顶部保护、绘制提示居中、顶点序号与辅助操作分层；悬浮面板宽度上限 228dp、文本 Ellipsis 与真实阶段读屏状态。
