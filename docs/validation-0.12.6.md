# 自律 0.12.6 · 切页与物理微交互

版本号 0.12.6，versionCode 51。本轮只改 UI 组织、展示缓存与动效，未改 Engine、Store、地图围栏、应用限额、统计仓库或备份结构。

## 实施

- 统计、应用使用、计划管理改为独立且有稳定 key/contentType 的 LazyColumn 条目。统计分布和应用行按需创建，未把整张长列表塞进一个 item。列表保存滚动状态；加载期用临时状态，避免将保存的位置压回顶部。统计的 Activity 内缓存只保存上次显示结果，原仓库刷新照常执行。
- 一级页与全屏子页保持主题不透明底板；设置的预测返回及原有隐藏退出内容语义保护继续沿用。导航统一以旧页 65ms 退场、新页延迟 45ms、12dp 位移和阻尼 1/刚度 550 的弹簧接入。关闭动画时直接渲染目标页，修复进行中的旧转场仍保留页面的情况。
- 专注顶部为任务/应用限额与悬浮球开关两行控制；本次配置在沙漏页脚，紧凑视口压缩间距。配置展开只由外壳的阻尼 .85/刚度 520 高度动画负责，移除叠加的内部高度动画，按钮区保持稳定。
- 应用使用页固定“过去7天使用 / 下周限额计划”，已选应用时有 56dp 快捷条。计划页复用顶栏数量、加号和单行筛选，置顶由 lazy item 位置弹簧处理。
- 数字使用有限的垂直换字过渡；进度与柱高采用阻尼 .88/刚度 400 的弹簧，动画值尽量在绘制阶段读取。关闭动画时绘制实际终值，语义始终报告实际值。
- 分段切换、成功标记完成、开始/暂停专注的既有触觉反馈直接复用。GlassSwitch/GlassCheckbox 新增一次输入反馈；纯外部状态更新不触发。分析应用整行的反馈保持一次，不与只读勾选图案重复。
